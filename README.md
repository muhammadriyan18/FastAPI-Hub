# FastAPI-Hub 🚀

A beginner-friendly project to learn and practice **FastAPI** using Python.

## 🛠️ Technologies
- Python
- FastAPI
- Uvicorn

## 🎯 Purpose
- Learn FastAPI fundamentals.
- Practice API development.
- Understand backend development.
- Build practical projects.

## 🚀 Installation

```bash
git clone https://github.com/muhammadriyan18/FastAPI-Hub.git
cd FastAPI-Hub
pip install fastapi uvicorn
```
